# دعوة زفاف إلكترونية 💍

موقع دعوة زفاف عربي (RTL) — صفحة واحدة، بدون أي مكتبات خارجية، جاهز للنشر على GitHub Pages
ثم تحويله إلى فيديو عمودي (٩:١٦) جاهز للواتساب والإنستقرام.

> ⚠️ كل البيانات في الموقع **تجريبية** (سارة وأحمد، ١١ يونيو ٢٠٢٧) — تُبدّل من ملف واحد:
> `assets/js/config.js`

---

## ١. المعاينة محلياً

```bash
cd New_wedding_invetation
python3 -m http.server 8080
# ثم افتح: http://localhost:8080
```

المعاينة داخل المتصفح المدمج في Arena: شغّل نفس الأمر هنا وستظر لك نافذة معاينة مباشرة.

## ٢. تعديل الدعوة

كل ما تحتاجه في `assets/js/config.js` — لا تلمس HTML/CSS:

| الحقل | الوصف |
|---|---|
| `bride` / `groom` | الاسم بالعربي، باللاتيني، الحرف الأول، اسم العائلة |
| `quote` | الآية أو الاقتباس + المصدر |
| `dateISO` | **الأهم** — تاريخ ووقت الحفل بصيغة `YYYY-MM-DDTHH:mm` (يشغّل العدّ التنازلي) |
| `dateAr` / `hijriNote` | التاريخ الهجري المكتوب يدوياً |
| `venue` | اسم القاعة، المدينة، العنوان، رابط خرائط جوجل |
| `timeline` | برنامج الحفل (وقت + عنوان + ملاحظة) |
| `whatsapp` / `phone` | أرقام تأكيد الحضور |
| `theme` | `emerald` \| `navy` \| `blush` \| `ivory` |
| `music` | مسار ملف mp3 اختياري للموسيقى الخلفية |

### الثيمات
بدّل قيمة `theme` في `config.js` وجرّب: أخضر زمردي (الافتراضي)، كحلي، وردي، عاجي.

### إضافة موسيقى
1. ضع ملف `song.mp3` في `assets/audio/`.
2. في `config.js`: `music: 'assets/audio/song.mp3'`.
3. زر تشغيل/إيقاف يظهر تلقائياً أسفل الشاشة.

### إضافة ألبوم صور (اختياري)
1. ضع الصور في `assets/img/` (jpg مضغوطة، عرض ١٢٠٠px يكفي).
2. أضف في `config.js`:
```js
gallery: ['assets/img/1.jpg', 'assets/img/2.jpg'],
```
> قسم الألبوم غير مفعّل في القالب الحالي — أخبرني وأضيفه مع تصميم يناسب باقي الصفحة.

## ٣. النشر على GitHub Pages (رابط يُرسل للضيوف)

1. ارفع الملفات إلى المستودع (الفرع `main`).
2. **Settings → Pages → Source: Deploy from a branch → Branch: `main` / root** → Save.
3. بعد دقيقة يصبح الرابط:
   `https://shahd1982001.github.io/New_wedding_invetation/`

الموقع يعمل بدون إنترنت خارجي (كل الخطوط محلية) — سريع جداً على شبكات الجوال.

## ٤. رفع فيديو مرجعي للمستودع (باش نحلّله ونقلّدوه)

**نعم — ينفع.** لكن انتبه لحدود GitHub:

| الطريقة | الحد الأقصى | ملاحظة |
|---|---|---|
| رفع عادي `git push` | تحذير بعد **50 م.ب** — منع بعد **100 م.ب** | الملف المرفوض لازم يُحذف من التاريخ |
| الرفع من موقع GitHub | **25 م.ب** فقط | أسهل طريقة من الجوال/اللابتوب |
| Git LFS | حسب الخطة (1–2 ج.ب) | يحتاج تنصيب LFS |
| YouTube / Drive + رابط | بلا حد | إذا الفيديو طويل أو ثقيل |

### الطريقة الأسهل (من المتصفح)
1. افتح المستودع على GitHub → **Add file → Upload files**.
2. اسحب الفيديو إلى مجلد `reference/` (أنشئه إن لم يوجد — أو اسمه `video/`).
3. **Commit changes**.

أو من الطرفية:
```bash
mkdir -p reference
cp /path/to/الفيديو.mp4 reference/reference.mp4
git add reference/reference.mp4
git commit -m "add reference video"
git push
```

### نصائح مهمة
- **حوّله إلى mp4 (H.264) وقلّل الحجم تحت ٢٥ م.ب** إن قدرت — أسهل وأسرع في التحليل:
  ```bash
  ffmpeg -i input.mov -vf "scale=-2:720" -c:v libx264 -crf 26 -an reference/reference.mp4
  ```
- الاسم بالحروف اللاتينية أفضل (`reference.mp4`) لتجنّب مشاكل الترميز في الروابط.
- إذا الفيديو أكبر من ١٠٠ م.ب: **لا ترفعه للمستودع** — ارفعه على يوتيوب (غير مدرج) وأرسل الرابط، أو ارفعه هنا كمرفق في المحادثة.

### فيديو طويل؟ قسّمه إلى مقاطع ✅
الأداة تقرأ **كل المقاطع بالترتيب** وتفهم القصة كاملة:

```bash
ffmpeg -i wedding.mp4 -c copy -map 0 -segment_time 60 -f segment \
       -reset_timestamps 1 reference/part-%02d.mp4
```

ثم ارفع `part-01.mp4`, `part-02.mp4` … إلى `reference/` (كل مقطع أقل من 25MB).
سمِّها بأرقام بخانتين (`01`, `02`, `10`) — الترتيب يتبع الرقم.

بعد الرفع:
```bash
node tools/analyze-video.mjs reference/
```
يخرج: `report.json` (خريطة كل مقطع + توقيته التراكمي)، `notes.md` (قالب تحليل)،
و`frames/part-XX/` (إطار كل ~١.٢ ثانية بدقة 720px).

📖 دليل مفصّل بالعربي: [`docs/كيف-ترفع-الفيديو.md`](docs/كيف-ترفع-الفيديو.md)

### ماذا أفعل به بعد الرفع؟
1. أستخرج إطارات (frames) عبر `ffmpeg` وأقرأها بالتفصيل.
2. أستخرج **الوقت والمدة، الإيقاع، الخطوط، الألوان (hex)، الحركة، الانتقالات، الموسيقى**.
3. أكتب لك `docs/video-analysis.md`: تحليل مشهد بمشهد + قائمة عناصر لإعادة البناء.
4. أنفّذ الموقع بنفس الأسلوب (نفس الألوان/الخطوط/الإيقاع لكن بأسمائكم وتاريخكم).
5. أحوّل الموقع إلى فيديو ١٠٨٠×١٩٢٠ عبر سكربت `tools/render-teaser.mjs`.

> يكفي رفع الفيديو وتكتب لي «رفعته» — أكمّل من هناك.

## ٥. من الموقع إلى فيديو

الحلقة كاملة تعمل محلياً (بدون خدمات مدفوعة):

```bash
bash tools/setup.sh                       # يثبّت Chromium + ffmpeg (مرة واحدة)
node tools/render-teaser.mjs \
  --url http://localhost:8080 \
  --out preview/teaser.mp4
```

السكربت:
1. يفتح الصفحة بمقاس ٥٤٠×٩٦٠ (DPR=2 → ١٠٨٠×١٩٢٠).
2. يسجّل الشاشة عبر Chrome DevTools (`Page.startScreencast`).
3. يفتح الدعوة، ثم يمرّ على الأقسام بحركة سلسة.
4. يحوّل الإطارات إلى MP4 بـ `ffmpeg` مع fade in/out.

**الناتج:** `preview/demo-teaser.mp4` — ديمو ٢٣ ثانية من القالب الحالي.

## ٧. ملاحظات تقنية

- بدون أي اعتماد خارجي (لا React، لا Tailwind، لا CDN) — يفتح حتى بدون إنترنت.
- `prefers-reduced-motion` مدعوم، والخطوط محلية، والألوان بتباين كافٍ.
- تأكيد الحضور يفتح واتساب برسالة جاهزة (بدون سيرفر أو قاعدة بيانات).
  لو تبي نموذج يُسجّل في Google Sheets أو Notion — أضيفه.
- التاريخ الهجري مكتوب يدوياً في `config.js` (التحويل التلقائي يختلف يوم أو يومين حسب الرؤية).
